## Overview
This project implements a small **Retrieval-Augmented Generation (RAG)** based
question-answering system over company policy documents such as Refund,
Cancellation, and Shipping policies.

The goal of this assignment is to demonstrate:
- Prompt engineering and iteration
- Grounded, non-hallucinated LLM responses
- Basic RAG pipeline design
- Evaluation and edge-case handling
